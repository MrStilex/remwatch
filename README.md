# remwatch

`remwatch` — панель мониторинга нод и сервисных логов (на базе Loki).

Этот README специально короткий: только обзор того, что уже есть в интерфейсе.

## Страницы

### 1) `Dashboard` (`/`)
- Общие метрики панели.
- Таблица нод (статус, онлайн, трафик total/speed).
- Быстрые блоки с метриками и логами.

Что можно делать:
- Смотреть текущее состояние системы и сети.
- Контролировать активных/просроченных/лимитных пользователей.
- Видеть свежие логи панели и подписок.

### 2) `Nodes` (`/nodes`)
- Полная таблица нод с индикаторами здоровья и трафика.
- Точка управления нодами.

Что можно делать:
- Смотреть статус нод и сетевые показатели.
- Добавлять новую ноду через модальное окно.
- Переходить в деталку конкретной ноды.

### 3) `Node Detail` (`/nodes/:name`)
- Детальная статистика по выбранной ноде.
- Представления с ошибками.

Что можно делать:
- Анализировать историю метрик ноды.
- Открывать целевые error-логи по ноде.

### 4) `Logs` (`/logs`)
- Список источников логов в Loki (`service/node/source/container`).
- Показывает время последнего обновления источника.

Что можно делать:
- По кнопке загружать список источников за выбранный период (`15m`–`7d`).
- Видеть, какие источники логов активны.
- Запускать удаление логов выбранного источника из Loki.

### 5) `Website/Bot Journal` (`/journal`)
- Страница поиска по содержимому логов сервисов.
- Фильтры: текст, node, service, level, период, лимит.

Что можно делать:
- Искать логи сайта/бота по условиям.
- Сужать выдачу по времени и фильтрам.
- Управлять сервисами через модалку `Управление`.

### 6) `Login` (`/login`) и `Change Password` (`/change-password`)
- Страницы авторизации и смены пароля.

## Стек (верхнеуровнево)

- Frontend: React + Vite
- Backend: Fastify (JWT auth, API routes)
- Логи: Loki
- Агенты: Vector + node-exporter (включены скрипты установки)

## Структура репозитория

- `frontend/` — страницы и компоненты UI
- `backend/` — API и авторизация
- `loki/` — конфиг и артефакты Loki
- `vector/` — конфиги Vector для доставки логов
- `service-agent-install.sh` — установщик сервисного агента
- `docker-compose.*.yml` — dev/deploy стеки

## Примечания

- Сейчас есть два логовых экрана:
  - `/logs` — список/управление источниками логов.
  - `/journal` — поиск по тексту логов.
- Некоторые операции (например физическое удаление в Loki) зависят от runtime-настроек Loki.
